# a

Tehtävänantona oli asentaa jokin uusi demoni käsin ja testata lopputulos.

Päätin asentaa Redis demonin. Redis (Remote Dictionary Server) on nopea, pääasiassa keskusmuistissa toimiva NoSQL-tietokanta ja välimuisti. Se mahdollistaa erittäin matalan viiveen luku- ja kirjoitusoperaatiot. (Wikipedia).

Ensin latasin paketin.

    sudo apt-get update
    sudo apt-get install redis-server

-t = vain TCP yhteydet

-n = näytetään portit numeromuodossa

-p = näytetään prosessit

# c

Tässä tehtävänä oli muuttaa asetustiedstoa masterilla ja ajaa ansible uudestaan, sekä osoittaa että asetukset tulivat käyttöön.

Tein redis kansioon alikansion `mkdir files`. Kopioin sinne redisin asetustiedoston `cp /etc/redis/redis-conf ~/ansible/roles/redis/files/redis.conf`
Vaihdoin omistajan ja ryhmän `chown sofia:sofia redis.conf`. Tarkoituksena, että rediksen asetustiedostoa voi muokata helposti ansiblen roolien redis kansiosta ilman sudoa. 

Sitten lisäsin tasks kansion main.yml tiedostoon cp moduulin:

<img width="278" height="193" alt="kuva" src="https://github.com/user-attachments/assets/ce88adcc-8104-40b0-b951-978ceea92e71" />

 Tarkoituksena, että jos asetustiedostoa muutetaan, niin se kopioidaan etc kansioon. Handler ajetaan, kun tiedostoon tulee muutoksia ja se käynnistää rediksen uudelleen, jotta uudet asetukset tulevat voimaan. Sitten piti vielä tehdä kyseinen handler.

 <img width="210" height="67" alt="kuva" src="https://github.com/user-attachments/assets/31ce5b4a-1dac-4022-af51-a8db0309c7ab" />
