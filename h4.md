## Configuration Management of Distributed Systems over Unreliable and Hostile Networks

-DLS = Domain-Specific Language, esim. SQL, HTML ja CSS

-DLS:t voi olla tosi monimutkaisia ja laajoja

-esim. Salt DLS on erittäin laaja: sisältää 510 tilafunktiota, joiden avulla ylläpitäjä voi hallita agenttikoneiden tilaa. Näiden dokumentaatio on yli 20 000 rivin ja yli 75 000 sanan mittainen.

-Mozillan Puppet-konfiguraatiossa eniten käytettyjä komentoja oli 13 ja ne kattoivat jo 87% kaikesta käytöstä

-sama ilmiö näkyi myös Yhdysvaltain hallinnon Puppet-konfiguraatioista

-vaikka CM-työkaluissa on paljon erilaisia toimintoja, käytännössä vain pieni osa niistä kattaa suurimman osan tavallisista käyttötapauksista.

-Konfiguraationhallinnan tärkeimpiä toimintoja ovat ohjelmistojen asentaminen, tiedostojen hallinta, palveluiden hallinta sekä käyttäjien ja ryhmien hallinta.

# a

Tehtävänantona oli asentaa jokin uusi demoni käsin ja testata lopputulos.

Päätin asentaa Redis demonin. Redis (Remote Dictionary Server) on nopea, pääasiassa keskusmuistissa toimiva NoSQL-tietokanta ja välimuisti. Se mahdollistaa erittäin matalan viiveen luku- ja kirjoitusoperaatiot. (Wikipedia).

Ensin latasin paketin.

    sudo apt-get update
    sudo apt-get install redis-server

Tarkistin että asennus onnistui:

<img width="443" height="63" alt="kuva" src="https://github.com/user-attachments/assets/cbf731c4-10d8-458d-ad16-ad03156b268e" />

Redis kuuntelee oletuksena porttia 6379. `ss` tulee sanoista socket statistics ja `-` jälkeen tulee valitsimet. 

-t = vain TCP yhteydet

-l = vain kuuntelevat portit

-n = näytetään portit numeromuodossa

-p = näytetään prosessit
