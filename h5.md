# x

### Chacon and Straub 2014: Pro Git, 2ed: 1.3 Getting Started - What is Git?

-Git tallentaa projektin eri versioita, jolloin vanhoihin versioihin voidaan tarvittaessa palata.

-Git tallentaa projektin tilannekuvia eikä pelkästään tiedostoihin tehtyjä muutoksia.

-Git toimii pääasiassa omalla tietokoneella ilman verkkoyhteyttä

-Verkkoyhteyttä tarvitaan esimerkiksi silloin, kun halutaan työntää muutokset eteenpäin

-Projektin koko historia tallennetaan paikallisesti.

-Hash-arvojen avulla Git pystyy havaitsemaan, jos tallennettu tieto muuttuu tai vioittuu.

-Gitissä tiedostot voivat olla kolmessa tilassa: Modified, Staged ja Committed

### Gitin käyttö

`git add --all && git commit; git pull && git push` selitettynä. Git-komennot opin Tero Karvisen luennolta ja välimerkkien merkitykset löysin GNU:n dokumentaatiosta. (https://www.gnu.org/software/bash/manual/html_node/Lists.html).

-git = käytetään Git-versionhallintajärjestelmää

-add = lisätään muutokset staging-alueelle, jotta ne voidaan committata eteenpäin

- --all = lisätään kaikki muutokset, myös uusien tiedostojen lisäykset ja tiedostojen poistot

-&& = seuraava komento suoritetaan vain, jos edellinen komento onnistui

-git commit = tallennetaan staging-alueelle lisätyt muutokset paikalliseen Git-tietokantaan

- ; = komentorivi suorittaa seuraavan komennon edellisestä komennosta riippumatta siitä, onnistuiko edellinen vai ei

-git pull = haetaan muutokset etärepositoriosta ja yhdistetään ne omaan paikalliseen projektiin

-&& sama kuin aikaisemmin

-git push = lähetetään omat paikalliset commitit etärepositorioon

lähinnä 'git add --all && git commit; git pull && git push'. Selitä tuon komennon jokainen osa. Käytä apuna itse valitsemiasi lähteitä ja viittaa niihin.
