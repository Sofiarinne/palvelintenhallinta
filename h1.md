### Karvinen 2026: SSH public key - Login without password

-SSH asennetaan komennoilla sudo apt-get update, sudo apt-get -y install ssh

-Clauden mukaan -y tarkoittaa että kaikkiin jatkokysymyksiin esim. Do you want to continue, vastataan automaattisesti yes

-ssh demonin saa päälle: sudo systemctl enable --now ssh

-ssh localhost komennolla testataan toimiiko ssh yhteys ja komennolla w voidaan tarkistaa ketkä ovat kirjautuneena koneelle

-w on vähän kuin who, mutta näyttää tarkemmat tiedot

-avainpari generoidaan komennolla ssh-keygen, toisin kuin Windowsissa .exe päätettä ei tarvita Linuxissa

-head $HOME/.ssh/id*.pub komennolla näkyy julkinen avain, mutta headin tilalla voi yhtä hyvin käyttää myös cat komentoa

-komennolla ssh-copy-id käyttäjä@ip julkisen avaimen saa ns työnnettyä toiselle palvelimelle, mistä se tulee löytymään polusta .ssh/authorized_keys

-hyvä komento vianmääritykseen asiakkaan puolelta: ssh -v localhost

-vianmääritykseen serverin puolelta: sudo journalctl --follow ja sudo systemctl status ssh

### Karvinen 2026: Hello Ansible

-Ansible toimii SSH:n kautta ja orjakoneisiin tulee olla asennettuna SSH ja Python

-Ansiblen asennus: sudo apt-get install ansible micro bash-completion tree (micro bash-completion tree, ovat vapaaehtoisia lisäpaketteja, jotka tekevät Ansiblen käytöstä helpompaa

-Ansiblelle kannattaa tehdä oma kansio: esim mkdir ansible/

-On tarpeellista luoda tiedosto kontrolloitavista koneista, esim: micro hosts.ini (micro on tekstieditori joka luo esimerkissä hosts.ini nimisen tiedoston ja sitten sinne voi kirjoittaa)

-Tiedostoon hostit tulee kirjoittaa yksi host per rivi

-Esimerkki Ansiblen käytöstä: ansible all -a 'uptime' -i hosts.ini, jossa all tarkoittaa kaikkia inventoryn koneita, -a tarkoittaa argumenttia joka tässä tapauksessa on "uptime" ja -i kertoo mitä tiedostoa käytetään inventoryna, eli mille koneille komento suoritetaan

-Inventory tiedoston loppuun kannattaa kirjoittaa vielä [all:vars] ansible_python_interpreter=/usr/bin/python3, jotta saadaan häiritsevä varoitusilmoitus pois jokaiselta ansiblen ajolta

-ansible.cfg tiedostoon voidaan määrittää inventory tiedosto, jotta sitä ei tarvitse kirjoittaa jokaiseen ansible komentoon (esim. inventory = hosts.ini)

-Roolit ovat /roles kansiossa
