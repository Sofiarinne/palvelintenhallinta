# x,

-SSH asennetaan komennoilla sudo apt-get update, sudo apt-get -y install ssh
-Clauden mukaan -y tarkoittaa että kaikkiin jatkokysymyksiin esim. Do you want to continue, vastataan automaattisesti yes
-ssh demonin saa päälle: sudo systemctl enable --now ssh
-ssh localhost komennolla testataan toimiiko ssh yhteys ja komennolla w voidaan tarkistaa ketkä ovat kirjautuneena koneelle
-w on vähän kuin who, mutta näyttää tarkemmat tiedot
-avainpari generoidaan komennolla ssh-keygen, toisin kuin Windowsissa .exe päätettä ei tarvita Linuxissa
-head $HOME/.ssh/id*.pub komennolla näkyy julkinen avain, mutta headin tilalla voi yhtä hyvin käyttää myös cat komentoa
-komennolla ssh-copy-id käyttäjä@ip julkisen avaimen saa ns työnnettyä toiselle palvelimelle, mistä se tulee löytymään polusta .ssh/authorized_keys
-hyvä komento vianmääritykseen asiakkaan puolelta: ssh -v localhost
-vianmääritykseen serverin puolelta: sudo journalctl --follow ja sudo systemctl status ssh
